# WiFi Admin
Android app (English/Bangla) to manage a Tenda AC5 router: device list, block/unblock, speed limit.
No server needed: the app talks to the router directly over your home WiFi.
Download the APK from the Releases page. `laptop-server/` is an optional laptop version.


## AI Network Assistant

See [AI Network Assistant implementation and compatibility notes](docs/AI_NETWORK_ASSISTANT.md) and the [Gemini backend setup guide](ai-backend/README.md). The AI backend must be deployed separately; its Gemini key is never stored in the APK.
